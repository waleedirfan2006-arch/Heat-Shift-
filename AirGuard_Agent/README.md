# AirGuard Agent

This folder is for the AirGuard Data Quality Agent and Insight Agent implementation and supporting documentation.

- `data_quality_agent.py` — data cleaning and quality checks.
- `insight_agent.py` — evidence-based weather insights.
- `main.py` — runs the agent workflow.
- `generate_report.py` — generates the final report.

Add the project source files here. Do not upload `.venv/`, `__pycache__/`, secrets, or large datasets unless the team requires them.

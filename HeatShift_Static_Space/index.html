In the METAR, a group like 29/11 means temperature 29°C and dew point 11°C. Enter the first number.

A time like 201600Z means the 20th at 16:00 UTC. Add 5 hours for PKT (21:00); adjust the date if it crosses midnight.

The current METAR temperature is entered manually because Aviation Weather Center blocks browser requests from other websites. JMA forecast inputs are retrieved automatically. HeatShift does not learn from predictions requested here.

How the model has performed

The frozen model was trained on 16,463 NOAA station examples from 2022–2023. Fixed January–February 2024 validation MAE (model vs the persistence baseline) was Karachi 1.031 vs 1.397°C, Lahore 1.082 vs 1.131°C, and Multan 1.226 vs 1.355°C.

On the untouched 2024 locked test, Karachi scored 0.932 vs 0.892°C (the model was worse), Lahore 1.488 vs 1.923°C, and Multan 1.469 vs 1.896°C. Later evaluation and limitations are in the project page.

The approximate ranges below use training-only errors; they are not guaranteed to contain the actual temperature. This experimental estimate is not an official forecast or weather warning.

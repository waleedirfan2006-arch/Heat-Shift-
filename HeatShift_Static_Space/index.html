A SMALL MODEL, WITH VISIBLE LIMITS

From observation to estimate

  1. Start with a real station reading. Enter a recent whole-degree airport temperature and its exact-hour time. The report is entered manually; it is not independently authenticated by this page.
  2. Retrieve the forecast context. Open-Meteo provides ten JMA GSM previous-day forecast fields for the target hour. At least eight and the temperature field must be available. Missing optional fields use the model’s saved training medians.
  3. Run the frozen model in your browser. The model estimates a temperature change, which is added to your observed temperature. It does not learn from your requests.
  4. Compare and keep a receipt. The baseline repeats today’s reading. A historical error band is shown for the model; it does not guarantee coverage.

If the weather service fails, choose baseline-only mode explicitly. We never label the baseline as an AI forecast.

Source access: Aviation Weather Center · Open-Meteo Previous Runs API (CC BY 4.0; processed into model inputs).

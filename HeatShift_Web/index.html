The prediction model

Waleed’s frozen HistGradientBoosting model estimates airport temperature 24 hours ahead. Original parameters and inference code are preserved.

It uses a recent station reading from the automatic pipeline or manual entry, plus JMA previous-day forecast fields. A persistence baseline is shown beside every result.

The quality agent

Mateen’s original Python code runs through the repository adapter. Its source fingerprint is verified before loading.

Short-gap interpolation is for offline review. Data age is unknown because the agent uses a server-local clock. This is not a complete source audit.

✧

The insight agent

Mateen’s original agent calculates numeric summaries with citations. Historical training observations and trusted project notes are provided.

A strict complete-question policy refuses unsupported scope. Canonical gold-table fingerprints and original source row IDs support numeric claims. Locked test, replay, reserve, and target values are excluded from agent tables.

Hourly pipeline

Last successful run: checking…

Checking the repository's latest hourly snapshot…

GitHub Actions fetches airport reports hourly; scheduled runs can be delayed. STALE describes the status snapshot: the latest airport reading can still be filled while it is less than four hours old. Older or future-dated readings stay unavailable. Raw, cleaned, processed tables and source manifests remain in run artifacts. Operational updates use a separate branch so the final code tag stays frozen. The model does not retrain.

Reproduced model evidence

Frozen model validation MAE: 1.102 °C versus the declared raw-reading baseline 1.235 °C on the same 1,783 rows. The observed reduction is 10.8%.

January was worse than baseline. The seven-day bootstrap improvement interval (-0.042 to 0.271 °C) includes no improvement. This reused development validation is not an independent final test. March calibration supplies the error bands shown for new predictions; future coverage is not guaranteed.

# HeatShift public demo

[Play or download the 2 minute 58 second video](HeatShift_Demo.mp4). The public repository and v1.0-final release provide access without a login.

This is a captioned walkthrough composed from actual deployed-dashboard screenshots captured on 21 October 2026. There is no audio narration and it is not a continuous screen recording. Forecasts shown are examples from their displayed observation time, not current readings when the video is watched.

It covers prediction, baseline, calibrated range, the unchanged quality agent, citations/document retrieval, unsupported location refusal, hourly updates and evaluation limits. See Project_Explanation_Viva.pdf for a live speaking outline.
